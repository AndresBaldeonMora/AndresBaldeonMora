## 👨‍💻 Sobre mí

Soy **desarrollador de software** con experiencia en aplicaciones de escritorio con **C# y WPF (MVVM)**, automatización de tareas con **Python** y soluciones basadas en **SQL Server**. Me interesa construir software útil, robusto y sencillo de mantener.

- 💼 **Stantec:** desarrollo de aplicaciones de escritorio para procesos de clientes de sectores minero e institucional; automatización de recolección de datos y consultas SQL para reportes operativos.
- 🔬 **Universidad Ricardo Palma:** experiencia en limpieza y procesamiento de datos de investigación biológica con Python y R, y en dashboards de Power BI.
- 🎓 **Formación:** Ingeniería Informática, Universidad Ricardo Palma.
- 🎯 **Enfoque:** desarrollo de software, automatización de procesos y análisis de datos.
- 🤝 **Abierto a conectar:** proyectos tecnológicos y oportunidades profesionales.
